# Tes Jodoh v2.0 💕

Aplikasi web kasual dan interaktif untuk mengukur persentase kecocokan cinta antara dua nama dengan animasi dinamis dan efek visual berbasis hasil.

## ✨ Fitur

- **Interaksi Tombol Hati Dinamis:** Tombol terkunci dan memudar sampai kedua nama dan gender dipilih, lalu berdenyut (*pulse*) saat siap.
- **Animasi Kalkulasi:** Angka bergulir cepat di tengah ikon hati selama 2 detik sebelum hasil akhir muncul.
- **Tema Dinamis & Efek Partikel:**
  - **Cocok (≥ 60%):** Tema cerah (*pink/gold*), hati menyala terang, dan efek ledakan *confetti* (menggunakan `canvas-confetti`).
  - **Kurang Cocok (< 60%):** Tema suram bernuansa gelap (*cool tone*), efek hati retak, rintik hujan animasi (*canvas*), dan pesan *"yahhh kaciannya kalian tidak cocok"*.
- **Tombol Mulai Ulang:** Reset instan untuk menguji pasangan baru tanpa perlu me-refresh halaman.
- **Easter Egg:** Skor khusus untuk kombinasi nama tertentu.
- **Desain Responsif:** Tampilan desktop horizontal dan otomatis bertumpuk rapi di perangkat mobile.

## 🛠️ Teknologi

- HTML5 (Semantic & SVG Icons)
- CSS3 (Custom Properties / Variables, Keyframes, Flexbox & Grid)
- Vanilla JavaScript (Canvas API)
- [canvas-confetti](https://www.npmjs.com/package/canvas-confetti) (via CDN)
